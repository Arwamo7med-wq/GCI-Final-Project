## ⚙️ Core Systems Architecture

### 1. Profit Maximization System (PMS)
[span_10](start_span)Unlike traditional risk assessment tools that arbitrarily accept or reject applications, PMS embeds financial constraints directly into the decision-making process[span_10](end_span). [span_11](start_span)[span_12](start_span)It calculates an individual probability of default for each customer and applies an **Optimal Decision Threshold** ($0.15$) to maximize net returns[span_11](end_span)[span_12](end_span).

[span_13](start_span)The underlying automated pipeline follows this workflow[span_13](end_span):
[span_14](start_span)`Data Integration ➔ Probability Prediction ➔ Optimal Threshold Evaluation ➔ Automated Financial Decision`[span_14](end_span)

[span_15](start_span)The system optimizes decisions based on the following financial logic[span_15](end_span):
$$\text{Net Profit} = (\text{Interest} \times \text{Successful Cases}) - (\text{Net Loss After Recovery} \times \text{Default Cases})$$

### 2. Default Trend Analysis
[span_16](start_span)Beyond automated filtering, the framework delivers high-level **Strategic Insights** to executive management by analyzing the root causes of defaults[span_16](end_span). [span_17](start_span)Feature Importance analysis highlights the four most critical risk drivers[span_17](end_span):
1. **[span_18](start_span)Average Credit Score:** The primary backbone of customer evaluation[span_18](end_span).
2. **[span_19](start_span)Repayment Period:** Shows a direct positive correlation with default probability[span_19](end_span).
3. **[span_20](start_span)Loan-to-Borrowed Ratio:** Reflects how well the loan match correlates with actual customer needs[span_20](end_span).
4. **[span_21](start_span)Required Loan Amount:** Dictates the scale of the customer's monthly financial obligation[span_21](end_span).
